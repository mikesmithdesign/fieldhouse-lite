# Fieldhouse Lite — free one-page template for coached gyms & strength clubs

A single-file HTML template with condensed poster type, real-people
photography and a free-session booking form. No build step, no
frameworks — open `index.html` and edit.

**Live demo:** (add your deployed URL here)

## Quick start

1. Edit the text directly in `index.html` — club name, classes, price, address.
2. Replace the photos in `img/` with your own (keep the filenames, or update
   the `src` paths).
3. Set your address, phone and email in the footer.
4. Upload anywhere — it's static files. Vercel, Netlify and GitHub Pages host
   it free.
